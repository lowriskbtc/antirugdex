Devnet only, enforced by genesis hash. Not by the wallet's network setting and not by a dropdown — this page reads the chain's genesis hash and refuses to build a transaction against anything but devnet. A mint is irreversible, and withdrawWithheldAuthority is fixed at creation and can never be changed by any instruction, so there is no safe way to be casual about which chain you are on.
