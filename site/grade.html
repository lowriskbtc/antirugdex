Advanced — your own RPC endpoint, and a pool to check

Stored in this browser only. Nothing is sent anywhere except to the endpoint you name.

What this page cannot do, stated rather than hidden. It reads chain state directly from your browser, so it uses a public endpoint by default — a keyed endpoint embedded in a web page is a published key. Measured from a browser: public devnet works but refuses getTokenLargestAccounts, so holder concentration reads NOT CHECKED; public mainnet refuses browser requests outright with a 403, so mainnet needs your own RPC URL under Advanced. Free tiers from Helius, Triton or QuickNode all work.

A NOT CHECKED row is the report telling you it could not look. That is not the same as telling you nothing is wrong, and it is why those rows are flagged instead of quietly omitted. Pool checks need the CLI grader, and the report says so too.

There is deliberately no pass/fail badge. A badge that is easy to pass launders bad launches.
